# Licencias de terceros

## Fuentes tipográficas

Las fuentes del diseño (Figma) se incluyen en `shared/src/commonMain/composeResources/font/`.
Ambas están bajo la licencia SIL Open Font License 1.1, que permite usarlas y distribuirlas
dentro de una aplicación. El texto completo de cada licencia está en esta carpeta.

| Fuente | Uso | Archivos | Origen |
|---|---|---|---|
| Plus Jakarta Sans (fuente variable) | Texto | `plus_jakarta_sans.ttf` | https://github.com/google/fonts/tree/main/ofl/plusjakartasans |
| IBM Plex Mono (Medium, SemiBold, Bold) | Cifras | `ibm_plex_mono_*.ttf` | https://github.com/google/fonts/tree/main/ofl/ibmplexmono |
